Crea un nuovo componente React per lets-night.

Argomento: $ARGUMENTS (nome PascalCase, es. "EventCard", "BookingModal", "VenueHeader")

Crea `components/$ARGUMENTS.js` seguendo queste regole:
- Aggiungi `'use client'` solo se il componente usa hooks o event handlers
- Props tramite destructuring nel parametro della funzione
- Usa classi CSS custom da `globals.css` o utility Tailwind
- Brand color: `#12A0D7`
- Default export con il nome del componente

Dopo la creazione:
- Mostra il file creato
- Suggerisci dove importarlo (quale pagina/layout ne ha bisogno)
